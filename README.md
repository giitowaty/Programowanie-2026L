# MovieTracker

Prosty projekt wykonany podczas laboratoriów.

## Technologie

- HTML
- CSS
- JavaScript

## Funkcje

- Dodawanie filmów z walidacją formularza
- Sekcja "Moje filmy" - lista wszystkich dodanych filmów
- Sekcja "Filmy z 2025 roku" - osobna lista filmów z roku 2025
- Komunikat potwierdzający dodanie filmu
- Responsywny design
- Favicon
